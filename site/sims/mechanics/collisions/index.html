Բախումներ

իմպուլսի և էներգիայի պահպանման օրենքները

Ձախից՝ սայլակների իմպուլսները և ընդհանուր իմպուլսը (նշանը ցույց է տալիս ուղղությունը), աջից՝ կինետիկ էներգիաները, ընդհանուր կինետիկ էներգիան և անջատված ջերմությունը Q։ Կետագիծը սկզբնական արժեքի մակարդակն է։

Սայլակներ

Դրական արագությունն ուղղված է աջ։ Բախում լինելու համար ձախ սայլակը պետք է շարժվի աջից ավելի արագ՝ v1 > v2։

Բախման տեսակը

e = 1՝ կինետիկ էներգիան պահպանվում է։ e = 0՝ սայլակները կպչում են իրար և շարունակում շարժվել միասին։

Ցուցադրում

Պատերին բախվելիս ընդհանուր իմպուլսը փոխվում է, քանի որ պատը արտաքին մարմին է. այն պահպանվում է միայն սայլակների փոխադարձ բախման ժամանակ։

Անիմացիայի արագություն

Օրինակներ

m1v1 + m2v2 = m1v1′ + m2v2′
e = (v2′ − v1′) / (v1 − v2)
v1′ = [(m1 − e·m2)v1 + (1 + e)m2v2] / (m1 + m2)
v2′ = [(m2 − e·m1)v2 + (1 + e)m1v1] / (m1 + m2)
Q = (1 − e²)·μ(v1 − v2)² / 2,
μ = m1m2 / (m1 + m2)

Իմպուլսի և էներգիայի պահպանումը բախման ժամանակ

Երբ երկու սայլակ բախվում է, նրանց միջև ազդող ուժերը ներքին են, իսկ շփում չկա։ Այդ պատճառով սայլակների ընդհանուր իմպուլսը բախումից առաջ և հետո նույնն է՝ m1v1 + m2v2 = m1v1′ + m2v2′, անկախ նրանից՝ բախումն առաձգական է, թե ոչ։ Գրաֆիկում «p» սյունը բախման ժամանակ չի փոխվում և միշտ հասնում է կետագծին։ Զանգվածների կենտրոնը շարժվում է հաստատուն արագությամբ նաև բախման պահին։

Կինետիկ էներգիայի պահպանումը կախված է բախման տեսակից։ Բացարձակ առաձգական բախման դեպքում (e = 1) կինետիկ էներգիան պահպանվում է, իսկ սայլակների հարաբերական արագությունը փոխում է միայն նշանը։ Բացարձակ ոչ առաձգական բախման դեպքում (e = 0) սայլակները կպչում են իրար և շարժվում են ընդհանուր u = (m1v1 + m2v2) / (m1 + m2) արագությամբ, ընդ որում կինետիկ էներգիայի մի մասը վերածվում է ջերմության՝ Q։ Մասնակի առաձգական բախման դեպքում (0 < e < 1) էներգիայի կորուստը ավելի փոքր է։

Փորձեք հետևյալը. վերցրեք հավասար զանգվածներ և e = 1՝ սայլակները կփոխանակվեն արագություններով։ Ծանր սայլակը թեթևի վրա ուղարկելիս ծանրը գրեթե չի դանդաղում, իսկ թեթևը թռչում է գրեթե կրկնակի արագությամբ։ Միացրեք պատերը և e = 1՝ սայլակները կշարժվեն առաջ ու հետ, իսկ կինետիկ էներգիան չի փոխվի։ Համեմատեք չափված Q-ն (1 − e²)·μ(v1 − v2)² / 2 բանաձևով հաշվածի հետ։

Պայմաններ

b-ն առաջին սկավառակի շարժման գծի և թիրախի կենտրոնի հեռավորությունն է։ b = 0՝ կենտրոնական բախում, b ≥ r1 + r2՝ սկավառակները չեն բախվում։ Երկրորդ սկավառակը սկզբում դադարի վիճակում է։

Բախման տեսակը

Սկավառակները հարթ են, ուստի հարվածի ուժը ուղղված է կենտրոնները միացնող ուղղությամբ։ Այդ ուղղությամբ է գործում e-ն, իսկ ուղղահայաց բաղադրիչները չեն փոխվում։

Ցուցադրում

Անիմացիայի արագություն

Օրինակներ

p1 = p1′ + p2′ (վեկտորական)
sin α = b / (r1 + r2)
v2′ = (1 + e)·m1/(m1 + m2)·v·cos α
m1 = m2, e = 1 ⟹ φ = 90°

Բախում հարթության վրա

Երբ առաջին սկավառակը թիրախին հարվածում է ոչ կենտրոնով, սկավառակները շարժվում են տարբեր ուղղություններով։ Հարթ սկավառակների դեպքում հարվածի ուժն ուղղված է կենտրոնները միացնող գծով։ Այդ գծի ուղղությամբ սկավառակները փոխանակում են իմպուլս (այստեղ գործում են e-ի և պահպանման օրենքի բանաձևերը), իսկ ուղղահայաց ուղղությամբ յուրաքանչյուր սկավառակի արագության բաղադրիչը չի փոխվում։ α անկյունը որոշվում է b հեռավորությամբ՝ sin α = b / (r1 + r2)։

Իմպուլսը վեկտորական մեծություն է, ուստի p1 = p1′ + p2′ հավասարումը նշանակում է, որ երեք վեկտորները կազմում են փակ եռանկյուն։ Յուրաքանչյուր առանցքի վրա պրոյեկցիաները նույնպես պահպանվում են՝ տես px և py տողերը։ Եթե բախումը առաձգական է, ապա կինետիկ էներգիան նույնպես պահպանվում է։

Հատուկ դեպք՝ երբ m1 = m2, բախումը բացարձակ առաձգական է և թիրախը դադարի մեջ է։ Այդ դեպքում էներգիայի և իմպուլսի պահպանումից հետևում է, որ սկավառակները ցրվում են փոխուղղահայաց՝ φ = 90° (կենտրոնական բախման դեպքում առաջինը կանգ է առնում)։ Փոխեք b-ն և համոզվեք, որ անկյունը չի փոխվում, ապա նվազեցրեք e-ն. φ-ն կփոքրանա։
