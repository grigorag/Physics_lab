Միաժամանակության հարաբերականություն

Էյնշտեյնի գնացքը և երկու կայծակները

  • դիտորդ գնացքում
  • դիտորդ կառամատույցում
  • A կայծակի լույսը (հետևում)
  • B կայծակի լույսը (առջևում)
Իրադարձություններ

    Տարածաժամանակի դիագրամ. հորիզոնական առանցքը կոորդինատն է, ուղղաձիգը՝ ժամանակը։ Լույսի ճառագայթները 45° թեքությամբ ուղիղներ են, իսկ հորիզոնական կետագիծը ցույց է տալիս ընթացիկ պահը։

    Հաշվարկման համակարգ

    Ցուցադրում

    Անիմացիայի արագություն

    Չափումներ

    β = v/c
    —
    Լորենցի գործակից γ
    —
    Գնացքի երկարությունը
    —
    Կառամատույցի A և B հետքերի հեռավորությունը
    —
    Կայծակների միջև ժամանակը
    —
    Գնացքի դիտորդը տեսնում է B-ն
    —
    Գնացքի դիտորդը տեսնում է A-ն
    —
    Կառամատույցի դիտորդը տեսնում է A-ն
    —
    Կառամատույցի դիտորդը տեսնում է B-ն
    —
    γ = 1 / √(1 − v²/c²)
    Լորենցի գործակից
    x′ = γ(x − vt)
    t′ = γ(t − vx/c²)
    Լորենցի ձևափոխություններ
    L = L₀ / γ
    շարժվող գնացքի երկարությունը
    Δt′ = γ·v·L / c² = v·L₀ / c²
    կայծակների միջև ժամանակը գնացքի համակարգում

    L₀ = 600 մ,  c = 300 մ/մկվ

    Միաժամանա՞կ են հարվածել կայծակները

    Գնացքը շարժվում է կառամատույցի երկայնքով v արագությամբ։ Այն պահին, երբ գնացքի մեջտեղում նստած դիտորդն անցնում է կառամատույցի մեջտեղում կանգնած դիտորդի մոտով (այդ պահն ընդունված է որպես t = t′ = 0), կառամատույցի համակարգում երկու կայծակ հարվածում են գնացքի ծայրերին՝ հետք թողնելով և՛ գնացքի, և՛ կառամատույցի վրա։ Կառամատույցի համակարգում A և B հետքերը հավասարահեռ են դիտորդից, և երկու բռնկումների լույսը նրան է հասնում նույն պահին. նա եզրակացնում է, որ կայծակները հարվածել են միաժամանակ։ Գնացքի դիտորդն այդ ընթացքում շարժվում է առջևի բռնկման լույսին ընդառաջ և հեռանում հետևի բռնկման լույսից, ուստի B-ն տեսնում է ավելի շուտ, քան A-ն։

    Այժմ նույն իրադարձությունները դիտեք գնացքի համակարգում։ Այստեղ գնացքն անշարժ է, դիտորդը հավասարահեռ է նրա ծայրերից, իսկ լույսը երկու ուղղությամբ էլ տարածվում է նույն c արագությամբ. լույսի արագությունը նույնն է բոլոր իներցիալ հաշվարկման համակարգերում։ Եթե դիտորդը B-ի լույսը տեսել է ավելի շուտ, ուրեմն B կայծակն իսկապես ավելի շուտ է հարվածել՝ Δt′ = v·L₀/c² չափով։ Մի համակարգում միաժամանակ, բայց տարածության տարբեր կետերում տեղի ունեցած իրադարձությունները մյուս համակարգում միաժամանակ չեն. միաժամանակությունը հարաբերական է։ Իսկ այն, ինչ տեղի է ունենում նույն կետում և նույն պահին (օրինակ՝ երկու լուսային ազդանշանների հանդիպումը կառամատույցի դիտորդի մոտ), համընկնում է բոլոր համակարգերում։

    Փորձեք. ընտրեք β = 0.6 և համեմատեք իրադարձությունների ցուցակը երկու համակարգերում. հերթականությունը, որով յուրաքանչյուր դիտորդ ստանում է ազդանշանները, չի փոխվում, փոխվում են միայն ժամանակի արժեքները և կայծակների հերթականությունը։ Ուշադրություն դարձրեք նաև երկարություններին. կառամատույցի համակարգում կրճատված է գնացքը, իսկ գնացքի համակարգում՝ կառամատույցը (նրա սալիկները նեղանում են)։ Փոքրացրեք արագությունը մինչև β ≈ 0.1. տարբերությունը գրեթե անհետանում է, այդ պատճառով էլ առօրյա կյանքում մենք այն չենք նկատում։
